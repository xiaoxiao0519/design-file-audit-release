# Figma 文件结构与 Auto Layout 规范参考

## 检查层级说明

文件结构规范的检查内容因层级不同而异：

| 层级 | 检查重点 | 跳过项 |
|------|----------|--------|
| 🏗 项目级 | 页面命名、页面排序、分割线页、废弃页、各页面内画板排列 | — |
| 📄 页面级 | 该页面内画板排列、废弃画板、画板间距 | 跨页面排序、分割线页 |
| 🖼 画板级 | — | 整个文件结构维度跳过 |

## 文件结构规范

### 推荐页面结构

> 核心思路：**设计稿按版本迭代拆分页面**，每个迭代/交付周期一个页面，便于追溯和管理。

```
📄 📦 组件库                ← 团队组件与变体
📄 📐 设计规范              ← Token、样式、间距说明
📄 ─────────                ← 分割线页，分隔基础设施与迭代区
📄 🎨 2026.05.12  V2.0  检材交互升级     ← 当前迭代
📄 🎨 2026.05.20  V2.1  详情页优化       ← 当前迭代
📄 🎨 2026.06.03  V2.2  搜索重构         ← 进行中
📄 ─────────                ← 分割线页，分隔迭代区与废弃区
📄 🗂 废弃                  ← 不用的画板及废弃方案
```

### 版本迭代页命名规范

| 命名格式 | 示例 | 适用场景 |
|----------|------|----------|
| **日期 + 版本号 + 迭代名** | 🎨 2026.05.12  V2.0  检材交互升级 | **团队统一格式，三项缺一不可** |
| 仅版本号 + 迭代名 | 🎨 V2.0 检材交互升级 | ❌ 不符合规范，缺少日期 |
| 仅日期 + 迭代名 | 🎨 2026.05.12 检材交互升级 | ❌ 不符合规范，缺少版本号 |

### 版本迭代页管理规则

| 规则 | 说明 |
|------|------|
| 版本号连续递增 | 不得跳号，V2.0 → V2.1 → V2.2 |
| 同迭代集中放置 | 同一迭代的所有设计（含多状态/多端）放在同一页面 |
| 废弃方案及时清理 | 设计确认后将不用的画板及废弃的方案移入废弃页，保持迭代页只留最终的版本 |
| 进行中置顶 | 正在进行的迭代页保持在最上方，已完成的往下排 |
| 一页一迭代 | 不得将多个迭代混在同一页面 |

### 页面命名规范

| 格式 | 示例 | 说明 |
|------|------|------|
| Emoji + 迭代名 | 🎨 2026.05.12  V2.0  检材交互升级 | 迭代页用 🎨 |
| Emoji + 功能名 | 📦 组件库 / 📐 设计规范 / 🗂 废弃 | 固定功能页 |
| 分割线页 | ───────── | 分隔不同区域 |

### 画板排列规范

- 画板从左到右、从上到下排列，遵循用户流程顺序
- 画板间距统一：推荐 200px
- 同一流程的画板相邻排列
- 不同流程之间加大间距或添加分隔标注

## Auto Layout 规范

### 基本原则

1. **能用就用**：任何重复出现的容器类元素都应使用 Auto Layout
2. **方向正确**：大部分场景用垂直方向，横向排列用水平方向
3. **间距规范**：统一使用 4px、8px，保持4的倍数

### 何时使用 Auto Layout

| 元素类型 | 是否需要 | 原因 |
|----------|----------|------|
| 按钮 | ✅ 必须 | 内部图标+文字需要自适应 |
| 卡片 | ✅ 必须 | 内容长度变化需要自适应 |
| 列表项 | ✅ 必须 | 数据行长度可变 |
| 表单组 | ✅ 必须 | 输入框+标签+错误提示 |
| 导航栏 | ✅ 必须 | 菜单项数量可变 |
| 纯展示图 | ❌ 不需要 | 单一元素无需布局 |
| 固定背景 | ❌ 不需要 | 绝对定位更合适 |

### Resizing 设置参考

| 场景 | 父容器 | 子元素 | 说明 |
|------|--------|--------|------|
| 按钮文字自适应 | Hug | Hug（文字）Fill（背景） | 文字撑开按钮 |
| 卡片等宽 | Fill | Hug | 容器撑满，内容自适应 |
| 固定高度头尾 | Fixed | Hug | 头尾固定，中间滚动 |
| 混合布局 | Fill | 按需 | 根据具体需求设置 |

### 间距网格系统

```
基础间距值：4px、8px
核心规则：所有间距保持4的倍数

合法间距值：
  4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 36 / 40 / 48 / 56 / 64

❌ 非法间距值：3 / 5 / 6 / 7 / 9 / 10 / 13 / 15 / 17 ...
```

| 间距 | 用途 |
|------|------|
| 4px | 图标与文字之间、紧凑元素内间距 |
| 8px | 同组元素之间、小卡片内间距 |
| 12px | 相关元素分组 |
| 16px | 组件内主要间距 |
| 24px | 组件之间的间距 |
| 32px | 区块之间的间距 |
| 48px | 大区块分隔 |
| 64px | 页面区域分隔 |

### 常见 Auto Layout 问题

| 问题 | 原因 | 修复方式 |
|------|------|----------|
| 内容溢出容器 | 容器设置了 Fixed 而非 Hug | 改为 Hug 或调整约束 |
| 间距不统一 | 手动定位而非 Auto Layout | 添加 Auto Layout 统一间距 |
| 响应式失效 | 固定宽高未设置约束 | 使用 Fill Container + 约束 |
| 嵌套层级过深 | 过多包装层 | 合并冗余 Auto Layout 层 |
